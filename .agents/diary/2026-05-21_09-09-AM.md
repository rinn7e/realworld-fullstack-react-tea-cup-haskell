## 2. server.sh — Terminal Launcher Script

Spent considerable time iterating on the startup script to open all three servers (backend, frontend-web, frontend-admin) conveniently.

### Journey:
1. Started with `gnome-terminal --tab` calls.
2. Tried switching to **Tabby** (`tabby run`) — opened tabs but showed a prompt; reverted.
3. Tried switching to **Ghostty** — looked into its CLI and found it only supports opening new **windows**, not new tabs from the command line. No `--tab` equivalent exists.
4. Researched FP-language terminal emulators: **Termonad** (Haskell) also lacks CLI tab support.
5. Concluded that `gnome-terminal` is still the best option for scripted tab management on Linux.
6. Attempted various approaches to open 1 window with 3 tabs in a single `gnome-terminal` call — the `--` argument separator breaks subsequent `--tab` parsing.
7. Master solved it elegantly by splitting into two scripts:
   - **`server.sh`**: Opens a new `gnome-terminal` window and calls `server-core.sh` inside it.
   - **`server-core.sh`**: From within that window, runs three `gnome-terminal --tab` commands, which attach to the current window as tabs.

### Lesson learned:
`gnome-terminal --tab` attaches to the **currently focused** gnome-terminal window. By running `server-core.sh` inside the new window, subsequent `--tab` calls correctly open in that same window instead of spawning new ones.
