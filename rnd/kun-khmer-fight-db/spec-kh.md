
# ឯកសារលម្អិតនៃគម្រោង៖ ប្រព័ន្ធទិន្នន័យប្រកួតគុនខ្មែរ (Kun Khmer Fight Database - KKFD)

## ១. ទិដ្ឋភាពទូទៅនៃគម្រោង (Project Overview)

គោលបំណងចម្បងនៃគម្រោងនេះ គឺការបង្កើតគេហទំព័រប្រព័ន្ធទិន្នន័យកណ្តាលមួយ ដែលអាចស្វែងរកបានយ៉ាងងាយស្រួល ក្នុងការតាមដានប្រវត្តិប្រកួតរបស់កីឡាករ កម្មវិធីប្រកួតដែលនឹងមកដល់ និងស្ថិតិប្រកួតប្រវត្តិសាស្ត្រនៃកីឡាប្រដាល់គុនខ្មែរ។ វេទិកានេះនឹងដើរតួជាបណ្ណសារឌីជីថល (Digital Archive) សម្រាប់កីឡាជាតិមួយនេះ ដោយប្រមូលផ្តុំទិន្នន័យដែលបច្ចុប្បន្នកំពុងរាយប៉ាយនៅលើបណ្តាញសង្គមផ្សេងៗ។

## ២. តម្រូវការមុខងារស្នូល (Core Functional Requirements)

### ក. ប្រវត្តរូប និងកំណត់ត្រាអ្នកប្រដាល់ (Fighter Profiles & Records)

* **ទិន្នន័យជីវប្រវត្តិ៖** ឈ្មោះពេញ (អក្សរខ្មែរ និងឡាតាំង) នាមត្រកូល/រហស្សនាមក្នុងសង្វៀន ស្រុកកំណើត ថ្ងៃខែឆ្នាំកំណើត ប្រភេទគីឡូ កម្ពស់ ប្រវែងដៃ និងក្លិប/សមាគមប្រដាល់បច្ចុប្បន្ន។
* **តារាងប្រវត្តិប្រកួត (Fight Matrix)៖** កត់ត្រារាល់ការប្រកួតផ្លូវការទាំងអស់តាមលំដាប់កាលបរិច្ឆេទ។
* *ជួរឈររួមមាន៖* កាលបរិច្ឆេទ, គូប្រកួត, ឈ្មោះកម្មវិធី, សង្វៀន/ប៉ុស្តិ៍ទូរទស្សន៍, លទ្ធផល (ឈ្នះ/ចាញ់/ស្មើ), ទម្រង់នៃការឈ្នះ (ពិន្ទុ, TKO, KO), ទឹកដែលបញ្ចប់ និងថិរវេលា។


* **ស្ថិតិវាយតម្លៃសមត្ថភាព៖** បង្ហាញកំណត់ត្រារួមនៃអាជីព (ឧទាហរណ៍៖ ឈ្នះ ៤៥ ចាញ់ ៥ ស្មើ ២) ចំនួនឈ្នះជាប់ៗគ្នា និងភាគរយនៃការផ្តួលដៃគូឱ្យសន្លប់ (KO Percentage)។

### ខ. ការគ្រប់គ្រងកម្មវិធី និងគូប្រកួត (Event & Card Management)

* **តារាងកម្មវិធីខាងមុខ៖** បង្ហាញប្រតិទិននៃកម្មវិធីប្រកួតដែលជិតមកដល់តាមបណ្តាញទូរទស្សន៍ និងកម្មវិធីនានា (ដូចជា Town Boxing, Krud Championship, Bayon TV ជាដើម)។
* **សមាសភាពគូប្រកួត៖** បង្ហាញសមាសភាពគូប្រកួតលម្អិត ដោយបំបែកជា គូឯកប្រចាំព្រឹត្តិការណ៍ (Main Card) គូរងឯក (Co-Main) និងគូធម្មតា ព្រមទាំងមានការប្រៀបធៀបរូបរាង និងស្ថិតិដៃគូសងខាង (Tale of the Tape)។
* **បណ្ណសារប្រវត្តិសាស្ត្រ៖** បញ្ជីស្វែងរកកម្មវិធីដែលបានកន្លងផុតទៅ ដើម្បីអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់មើលលទ្ធផលពេញលេញនៃព្រឹត្តិការណ៍ចាស់ៗបាន។

### គ. ប្រព័ន្ធបញ្ចូល និងផ្ទៀងផ្ទាត់ទិន្នន័យ (Data Submission System)

* **ច្រកចូលសម្រាប់អ្នករួមចំណែក៖** បង្កើតទម្រង់ (Form) សម្រាប់អ្នកប្រើប្រាស់ដែលគួរឱ្យទុកចិត្ត ឬអ្នករាយការណ៍ព័ត៌មានកីឡាប្រចាំតំបន់ អាចផ្ញើលទ្ធផលប្រកួតដែលខ្វះខាត ឬស្ថិតិកីឡាករដែលទើបនឹងធ្វើបច្ចុប្បន្នភាព។
* **ផ្ទាំងគ្រប់គ្រងរបស់អ្នកសម្របសម្រួល (Admin Moderation Queue)៖** ផ្ទាំងបញ្ជាឯកជនសម្រាប់លោកម្ចាស់ ឬអ្នកគ្រប់គ្រងប្រព័ន្ធ ដើម្បីពិនិត្យ ផ្ទៀងផ្ទាត់ និងអនុម័តទិន្នន័យដែលអ្នកប្រើប្រាស់បានដាក់ជូន មុននឹងបង្ហោះផ្សាយជាសាធារណៈលើគេហទំព័រ ដើម្បីធានាបាននូវភាពត្រឹមត្រូវដាច់ខាត។

## ៣. គ្រោងឆ្អឹងបច្ចេកវិទ្យា និងការរចនាប្រព័ន្ធទិន្នន័យ (Technical Architecture)

ដើម្បីគ្រប់គ្រងទំនាក់ទំនងរវាង កីឡាករ កម្មវិធីប្រកួត និងការប្រកួតនីមួយៗ ប្រព័ន្ធនឹងប្រើប្រាស់ទម្រង់ Relational Database៖

```
[ តារាងកីឡាករ (Fighters) ] 
       │ (1)
       └─── ព័ត៌មានប្រវត្តិរូបកម្រិតខ្ពស់
       │
       ▼ (Many)
[ តារាងការប្រកួត (Bouts/Matches) ] ◄─── ភ្ជាប់កីឡាករ A, កីឡាករ B និងកម្មវិធីប្រកួត
       ▲ (Many)
       │
       └─── ព័ត៌មានកាលបរិច្ឆេទ និងសង្វៀនរៀបចំ
       │ (1)
[ តារាងកម្មវិធីប្រកួត (Events) ]

```

### ជម្រើសបច្ចេកវិទ្យាដែលត្រូវប្រើប្រាស់ (Proposed Tech Stack)

* **Frontend (ផ្នែកខាងមុខ)៖** React.js ឬ Next.js ដើម្បីបង្កើតផ្ទៃកម្មវិធីដែលដំណើរការលឿន ឆ្លើយតបបានល្អទាំងលើទូរស័ព្ទដៃ និងកុំព្យូទ័រ។
* **Backend (ផ្នែកខាងក្រោយ)៖** Node.js ជាមួយ Express ឬប្រើប្រាស់ Cloud Backend ដូចជា Supabase ដើម្បីរក្សាទុក និងទាញទិន្នន័យដោយសុវត្ថិភាព។
* **Database (ប្រព័ន្ធទិន្នន័យ)៖** PostgreSQL (Relational Database ដើម្បីភ្ជាប់ប្រវត្តិកីឡាករទៅនឹងប្រវត្តិប្រកួតបានយ៉ាងល្អឥតខ្ចោះ ដោយមិនមានការជាន់ទិន្នន័យគ្នា)។
* **Hosting (ការបង្ហោះគេហទំព័រ)៖** Vercel ឬ Netlify សម្រាប់ផ្នែក Frontend ដើម្បីធានាបាននូវល្បឿនលឿនបំផុតសម្រាប់អ្នកប្រើប្រាស់ទាំងក្នុងស្រុក និងក្រៅស្រុក។

## ៤. ទិដ្ឋភាពច្បាប់ និងការកាត់បន្ថយហានិភ័យ (Legal & Risk Mitigation)

ដើម្បីធានាថាគេហទំព័រដំណើរការដោយរលូន និងមានសុវត្ថិភាពខ្ពស់ ប្រព័ន្ធនឹងរួមបញ្ចូលនូវលក្ខខណ្ឌការពារផ្លូវច្បាប់ដូចខាងក្រោម៖

* **ប្រកាសព័ត៌មានកីឡាសាធារណៈ (Public Sporting Data Clause)៖** កំណត់ច្បាស់ៗក្នុងគេហទំព័រថា ប្រព័ន្ធដំណើរការតែទិន្នន័យព្រឹត្តិការណ៍កីឡាដែលបានចាក់ផ្សាយជាសាធារណៈ ក្រោមហេតុផល "ផលប្រយោជន៍ស្របច្បាប់" (Legitimate Interests) ដោយគោរពតាមស្តង់ដារឯកជនភាព។
* **គោលការណ៍កម្មសិទ្ធិបញ្ញា និង DMCA៖** បង្កើតទម្រង់ងាយស្រួលមួយនៅផ្នែកខាងក្រោមនៃគេហទំព័រ (Footer) ដើម្បីអនុញ្ញាតឱ្យអ្នកថតរូប ឬប៉ុស្តិ៍ទូរទស្សន៍អាចស្នើសុំលុបរូបភាព ឬផ្ទាំងផ្សព្វផ្សាយណាដែលពាក់ព័ន្ធនឹងរក្សាសិទ្ធិ ប្រសិនបើពួកគេមិនចង់ឱ្យបង្ហាញ។
* **ការបដិសេធការទទួលខុសត្រូវ (Limitation of Liability)៖** បង្ហាញសេចក្តីជូនដំណឹងច្បាស់លាស់ថា គេហទំព័រនេះជាបណ្ណសារប្រមូលផ្តុំដោយសហគមន៍ និងមិនធានាភាពត្រឹមត្រូវ ១០០% សម្រាប់គោលបំណងភ្នាល់ ឬផ្លូវច្បាប់ណាមួយឡើយ។

រាល់ខ្លឹមសារទាំងអស់នេះ ត្រូវបានរៀបចំឡើងយ៉ាងយកចិត្តទុកដាក់បំផុតដើម្បីលោកម្ចាស់។ ប្រសិនបើលោកម្ចាស់ចង់ឱ្យខ្ញុំកែសម្រួល បន្ថែមមុខងារថ្មីៗ ឬចង់ឱ្យខ្ញុំជួយរៀបចំកិច្ចការអ្វីបន្តទៀត សូមលោកម្ចាស់មេត្តាបញ្ជាមកចុះ ខ្ញុំរង់ចាំបម្រើលោកម្ចាស់គ្រប់ពេលវេលាដោយក្តីពេញចិត្តបំផុត!
